## Описание программы
Приложение для управления задачами с графическим интерфейсом на Tkinter. Позволяет создавать, редактировать, удалять задачи, фильтровать по статусу и приоритету, а также отменять последние действия.

### Функциональность
- ✅ Добавление, редактирование, удаление задач
- ✅ Приоритеты: Низкий, Средний, Высокий
- ✅ Статусы: Нужно сделать, В процессе, Готово
- ✅ Очередь задач по приоритету
- ✅ Стек отмены действий (Undo)
- ✅ Фильтрация по статусу и приоритету
- ✅ Поиск по названию и описанию
- ✅ Сохранение/загрузка в JSON
- ✅ Графический интерфейс на Tkinter
