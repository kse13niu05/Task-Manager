## Описание программы
Консольное приложение для генерации случайных задач различных типов с использованием паттерна **Factory**. Программа помогает разнообразить повседневные дела, предлагая случайные задачи для работы, спорта, учебы, хобби, здоровья и общения.

### Особенности
- 🎲 **Генерация случайных задач** - автоматическая генерация задач из предустановленных шаблонов
- 🏭 **Паттерн Factory** - гибкое создание задач различных типов
- 📊 **Очередь истории** - хранение последних 100 сгенерированных задач
- 🔍 **Фильтрация** - по типу задачи и уровню сложности
- ⏱️ **Оценка времени** - автоматический расчет времени выполнения
- ✅ **Отслеживание выполнения** - возможность отмечать выполненные задачи
- 💾 **JSON сохранение** - загрузка и сохранение истории
- 📈 **Статистика** - подробная аналитика по задачам
